## 0.1.0

First release.

- Remote panel in the activity bar with buttons to create an FTP or SFTP config file and to connect.
- Per-project `.ftpconfig`, compatible with the Pulsar/Atom `remote-ftp` format.
- FTP, FTPS (explicit and implicit) and SFTP (password, private key, ssh-agent/Pageant, keyboard-interactive/2FA).
- Remote file tree with Add File, Add Folder, Refresh, Rename, Delete and Download.
- Click a remote file to download and open it; saving uploads it.
- `.ftpignore` support and `watch` paths for files changed outside the editor.
- Drag and drop files or folders from the Explorer or the desktop onto the Remote panel to upload.
- Multi-select delete and download.
